Cross-Dataspace SPARQL Query

How a single SPARQL SELECT with UNION bridges two structurally different PMDCO graph patterns.

1. Why a UNION is needed

Both pipelines produce PMDCO-conformant RDF, but they land on different graph patterns because the source schemas encode the material-component relationship differently.

Catena-X graph pattern (Structure A)

The Catena-X SPARQL INSERT creates an intermediate material entity node between the component and its qualities. The component points to the material via BFO part-whole relations; the material then carries the qualities. Numeric values are typed as QUDT QuantityValues with qudt:numericValue (an xsd:decimal literal). 

# Component → material → quality → datum → QuantityValue
?component  obo:BFO_0000051  ?mat .
?mat        obo:RO_0000086   ?quality .
?quality    obo:IAO_0000417  ?datum .
?datum      obo:OBI_0001938  ?qv .
?qv         qudt:numericValue  ?value .    # xsd:decimal
?qv         qudt:unit          ?unit .     # QUDT unit IRI

Manufacturing-X graph pattern (Structure B)

The AAS2KG CONSTRUCT links qualities directly to the component — no separate material node. Numeric values are string literals accessed via pmd:PMD_0000006, and units use obo:IAO_0000039. These are different properties and different value types from Structure A, making a UNION mandatory. 

# Component → quality → value specification
?component  obo:RO_0000086   ?quality .
?quality    obo:OBI_0001938  ?qv .
?qv         pmd:PMD_0000006  ?value .    # string literal
?qv         obo:IAO_0000039  ?unit .     # QUDT unit IRI (different predicate)
Without PMDCO as the shared ontology, the two components could not even be in the same query. With PMDCO, both quality individuals use the same TTO/PMDCO type IRIs — tto:TTO_0000053 for tensile strength, tto:TTO_0000009 for yield strength — making a UNION across the two graph patterns possible.

2. The full query

PREFIX rdf:   <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
PREFIX rdfs:  <http://www.w3.org/2000/01/rdf-schema#>
PREFIX obo:   <http://purl.obolibrary.org/obo/>
PREFIX pmd:   <https://w3id.org/pmd/co/>
PREFIX tto:   <https://w3id.org/pmd/tto/>
PREFIX qudt:  <https://qudt.org/schema/qudt/>
PREFIX ex:    <http://example.org/assembly/>

# Starting point: the assembly graph links the two components
SELECT ?componentLabel
       (COALESCE(?materialLabel, ?componentLabel) AS ?material)
       ?property ?value ?unitLabel
WHERE {
  ex:TensionPulley_001 obo:BFO_0000051 ?component .
  ?component rdfs:label ?componentLabel .

  {
    # Structure A: Catena-X — separate material entity
    ?component obo:BFO_0000051 ?mat .
    ?mat rdfs:label ?materialLabel .
    ?mat obo:RO_0000086 ?quality .
    ?quality a ?qualityType .
    ?quality obo:IAO_0000417 ?datum .
    ?datum obo:OBI_0001938 ?qv .
    ?qv qudt:numericValue ?value .            # decimal literal
    OPTIONAL { ?qv qudt:unit ?unit }
    BIND(STRAFTER(STR(?unit), "unit/") AS ?unitLabel)
  }
  UNION
  {
    # Structure B: Manufacturing-X — qualities directly on component
    ?component obo:RO_0000086 ?quality .
    ?quality a ?qualityType .
    ?quality obo:OBI_0001938 ?qv .
    ?qv pmd:PMD_0000006 ?value .              # string literal
    OPTIONAL { ?qv obo:IAO_0000039 ?unit }
    BIND(STRAFTER(STR(?unit), "qudt/") AS ?unitLabel)
  }

  # Label resolution: instance label > type label > IRI fragment
  OPTIONAL { ?quality rdfs:label ?instanceLabel }
  OPTIONAL {
    VALUES (?qualityType ?typeLabel) {
      (tto:TTO_0000009  "yield strength")
      (tto:TTO_0000033  "elongation at fracture")
      (tto:TTO_0000053  "tensile strength")
      (pmd:PMD_0000618  "elastic modulus")
      (pmd:PMD_0000851  "melting point")
      (pmd:PMD_0000518  "impact strength")
    }
  }
  BIND(COALESCE(
    ?instanceLabel,
    ?typeLabel,
    STRAFTER(STR(?quality), "-qual-")
  ) AS ?property)

  # Drop rows where label resolution produced nothing
  FILTER(str(?property) != "")
}
ORDER BY ?componentLabel ?property

3. The result

Seven rows covering both components: four polymer properties from Catena-X (elastic modulus, impact strength, melting point, tensile strength) and three steel properties from Manufacturing-X (elongation at fracture, tensile strength, yield strength). The column names correspond directly to the SPARQL SELECT bindings.

Blue rows: Catena-X / PA6GF30 (Structure A). Purple rows: Manufacturing-X / Steel 316/4401 (Structure B). Both materialised from the same PMDCO ontology — different graph topologies, one query.

4. Live SPARQL endpoint

The cross-dataspace demo dataset is served by Apache Jena Fuseki on the PMD data portal. The endpoint accepts HTTP POST with Content-Type: application/x-www-form-urlencoded and Accept: application/sparql-results+json.
