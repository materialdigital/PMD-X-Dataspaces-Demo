Manufacturing-X Round-Trip Query

A SPARQL SELECT over urn:graph:mfgx-aas reconstructs the mechanical test results and chemical composition from the AAS-ontology RDF via CONCAT aggregation. The result is asserted against reference values extracted from the original AAS inspection document inspectiondocument_316_4401_alloy.json.

1. What the query verifies

Node B loads the AAS-ontology RDF (mfgx-aas.ttl, produced by py-aas-rdf) into urn:graph:mfgx-aas. The round-trip query navigates the AAS SubmodelElementCollection hierarchy — MechanicalTests → TensileTest__00__ → Property and ChemicalAnalysis → Property — using aasRf:idShort as the section anchor and aasP:value for the numeric values.

Reference: mfgx-reference.json — mechanical test results (tensile=632, yield=276, elongation=60) and chemical composition (9 elements: C, Cr, Mn, Mo, N, Ni, P, S, Si). Derived from inspectiondocument_316_4401_alloy.json.

2. Query structure

Two correlated sub-SELECTs aggregate each section into a JSON fragment. A numeric-only FILTER (REGEX matching ^-?[0-9]+) excludes empty fields and non-numeric metadata present in the AAS document. 

PREFIX aas:    <https://admin-shell.io/aas/3/0/>
PREFIX aasP:   <https://admin-shell.io/aas/3/0/Property/>
PREFIX aasRf:  <https://admin-shell.io/aas/3/0/Referable/>
PREFIX aasSMC: <https://admin-shell.io/aas/3/0/SubmodelElementCollection/>

SELECT (CONCAT(
  '{"mechanicalTests":{', ?mechJson, '},"chemicalAnalysis":{', ?chemJson, '}}'
) AS ?json)

FROM <urn:graph:mfgx-aas>
WHERE {

  # Mechanical: MechanicalTests → TensileTest__00__ → numeric Property
  {
    SELECT (GROUP_CONCAT(
      CONCAT('"', ?idShort, '":',
        IF(REGEX(STR(?val), '^-?[0-9]+(\\.[0-9]+)?([eE][+-]?[0-9]+)?$'),
           STR(?val), CONCAT('"', STR(?val), '"')))
      ; SEPARATOR=',') AS ?mechJson)
    WHERE {
      ?mechSMC a aas:SubmodelElementCollection ;
               aasRf:idShort "MechanicalTests" ;
               aasSMC:value ?testRun .
      ?testRun a aas:SubmodelElementCollection ;
               aasSMC:value ?prop .
      ?prop a aas:Property ;
            aasRf:idShort ?idShort ;
            aasP:value ?val .
      FILTER(?val != "" && REGEX(STR(?val), '^-?[0-9]+(\\.[0-9]+)?([eE][+-]?[0-9]+)?$'))
    }
  }

  # Chemical: ChemicalAnalysis → numeric Property (mass fractions)
  {
    SELECT (GROUP_CONCAT(
      CONCAT('"', ?idShort, '":',
        IF(REGEX(STR(?val), '^-?[0-9]+(\\.[0-9]+)?([eE][+-]?[0-9]+)?$'),
           STR(?val), CONCAT('"', STR(?val), '"')))
      ; SEPARATOR=',') AS ?chemJson)
    WHERE {
      ?chemSMC a aas:SubmodelElementCollection ;
               aasRf:idShort "ChemicalAnalysis" ;
               aasSMC:value ?prop .
      ?prop a aas:Property ;
            aasRf:idShort ?idShort ;
            aasP:value ?val .
      FILTER(?val != "" && REGEX(STR(?val), '^-?[0-9]+(\\.[0-9]+)?([eE][+-]?[0-9]+)?$'))
    }
  }

}
